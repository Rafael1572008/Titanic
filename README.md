 # Titanic - Data Science Study
 
 ![Status](https://img.shields.io/badge/status-em%20desenvolvimento-yellow)

## Descricao

Este repositorio contem um estudo de Data Science utilizando o dataset do Titanic, com foco em analise exploratoria e preditiva. O objetivo e prever a sobrevivencia dos passageiros com base em caracteristicas como idade, sexo e classe social, alem de explorar possiveis padroes temporais (branch time_series). Inspirado na competicao do Kaggle "Titanic: Machine Learning from Disaster", este projeto serve como exercicio educacional em Machine Learning e analise de dados.

## Objetivos

- Realizar analise exploratoria dos dados (EDA).
- Aplicar tecnicas de pre-processamento e engenharia de features.
- Desenvolver modelos de Machine Learning para prever sobrevivencia.
- Investigar aspectos de series temporais (branch time_series).
- Documentar o processo para aprendizado e colaboracao.

## Dataset

**Download:** [Kaggle Titanic Dataset](https://www.kaggle.com/c/titanic/data)

## Tecnologias e Bibliotecas

- **Linguagem:** Python 3.9+
- **Bibliotecas principais:** (definidas em `requirements.txt`)
  - `pandas`, `numpy` (manipulação de dados)
  - `matplotlib`, `seaborn` (visualizações)
  - `scikit-learn` (modelos de ML)
- **Ambiente:** [Visual Studio Code](https://code.visualstudio.com/)

Como Executar

1. Clone o repositório:
```bash
  git clone https://github.com/Rafael1572008/Titanic.git
  cd Titanic
```

2. Instale as dependencias:
```bash
   pip install -r requirements.txt
```
